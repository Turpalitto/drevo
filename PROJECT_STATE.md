- Производительность `renderTree`/`familyPath`/`bloodRelativesOf` — O(n²); на демо незаметно, на больших древах не проверялось.
- Локальный архив хранится в `localStorage` (лимит ~5 МиБ на origin), а фото — data URL до 600 КБ. При большом архиве возможен отказ сохранения. План: IndexedDB/OPFS.
- Схема БД без версии (`CREATE TABLE IF NOT EXISTS`), миграций нет.
- У человека один источник строкой (`source`); источников и цитат как объектов нет.
- Приблизительные даты (`ABT`/`BEF`/`AFT`) не поддерживаются — только точный год или ISO-дата.

## Working features

- Вход по семейному паролю (в базе — scrypt-хеш с солью), сессии, общая база SQLite в режиме WAL, защита от затирания через ревизии (409).
- Интерактивное SVG-древо, 4 режима подсветки родства, калькулятор связи, экспорт JSON/GEDCOM/CSV, импорт.
- Ежедневные копии: JSON архива и согласованный снимок базы `VACUUM INTO` (`data/backups/`, 30 дней).
- Стабильные идентификаторы людей (`uid`, GEDCOM 7 `UID`): сохраняются при выгрузке, импорте и слияниях; старым записям выводятся детерминированно.
- Отдача `index.html` со сжатием (brotli/zstd/gzip) и `ETag`; статика с `ETag` и `Cache-Control`.
- Гостевые заявки по секретной ссылке: отправка, очередь, подтверждение/отклонение владельцем. Данные живых людей по ссылке скрыты (год рождения не отдаётся).
