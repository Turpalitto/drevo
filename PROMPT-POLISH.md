# Мастер-промпт: довести «Корни» до совершенства

Роль: ты отвечаешь за финальное качество проекта «Корни» (семейное древо, Node.js без зависимостей + SQLite + index.html). Каждое обещание проверяется запуском, а не на словах.

## Статья 1 — Надёжность и безопасность сервера
- Ограничить память под rate-limit (`attempts`) и чистить просроченные попытки; сессии удалять по таймеру, а не только lazily.
- Добавить security-заголовки: CSP для HTML, nosniff, Referrer-Policy, X-Frame-Options.
- Cookie: помечать Secure, когда запрос пришёл по HTTPS (x-forwarded-proto).
- Graceful shutdown (SIGTERM/SIGINT): корректно закрыть SQLite, пока ничего не потеряно.
- /healthz должен отвечать ok только если база реально читается/пишется.

## Статья 2 — Корректность API
- Перепроверить все эндпоинты вручную скриптом: логин, rev, GET/PUT archive с конфликтом 409, contribution-link, заявки (submit/approve/reject), авторизация, отклонённые токены, битые тела.
- Одинаковые правила валидации на клиенте и сервере (уже так; проверить тестом).

## Статья 3 — Автотесты
- Добавить Node test runner (node:test) без внешних зависимостей, покрывающий: здоровье, вход/сессию, сохранение архива и конфликт ревизий, валидацию людей, поток заявок guest→approve.
- Прогнать тесты, exit code 0 обязателен.

## Статья 4 — Ручная проверка клиента
- Показать работающее приложение через браузер: вход, древо, диалоги, консоль без ошибок.

## Статья 5 — Документация и память
- README (запуск, безопасность, Docker), PROJECT_STATE/TODO/DECISIONS обновить по факту.
- Память проекта: pm-checkpoint по протоколу AGENTS.md.

## Критерий готовности
Тесты зелёные, реальный прогон в браузере без ошибок консоли, документация соответствует коду, ничего «segue» — только проверенные изменения.
