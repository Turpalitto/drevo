## Этап 4 — древо и визуальная система (сделано)

Что изменилось в `index.html`:
- **Уровни детализации** по масштабу: `lod-far` (< 0.72) — только крупное имя (25 px) и годы, `lod-mid` (< 0.95) — карточка без подписи, иначе — портрет/годы/подпись. `lod-map` (< 0.28) — карта из блоков без текста (для «Всё древо» на большой семье) плюс поясняющий тост.
- **Узел брака**: от отца и матери две «руки» к точке брака, от неё одна общая линия к ребёнку (`union-arm`/`union-dot`/`union-child`). Цвета отца/матери сохранены, `data-parent2` учтён в подсветке родства.
- **Раскладка**: порядок в ряду по паре родителей (братья и сёстры рядом, пары неразлучны), позиции — изотоническая регрессия (PAVA) к желаемым центрам, 4 прохода вниз/вверх. Убрано центрирование узкого ряда по самому широкому: раньше 2 корневые пары уезжали на 7–9 тыс. px от детей.
- **Камера**: `animateCameraTo`, `ensureVisible` (двигает только если человек вне кадра), `revealPerson`, `rootPerson` (старший без родителей), `partnersOf` (супруг = явная связь или второй родитель). `fitTree` центрирует корни и пару целиком, `MIN_READABLE_SCALE=0.52`, вертикальное центрирование, если древо влезает.
- **Стабильность кадра**: открытие карточки/панели не сбрасывает масштаб, сворачивание возвращает уменьшившееся древо в кадр, подсветка родства снимается при закрытии карточки (иначе всё древо оставалось приглушённым).
- **Свёрнутая ветка**: скрывает и супругов скрытых людей (если у супруга нет своих видимых детей) — раньше в ряду оставались одинокие карточки.
- **Телефон**: `.stage` получает `clamp(320px,54dvh,560px)` (было min-height 280px), первый экран — корни с парой по центру.
- **Тесты**: новый `test/ui/stage4.js` (27 проверок), `npm run test:ui` = stage3 + stage4, снимки в `test/ui/out/` (gitignore).

Проверено: `npm test` 8/8, `npm run test:ui` 36/36 + 27/27, консоль без ошибок; снимки 1440 и 390 (демо, 68 человек, мужская линия, свёрнутая ветка, карта).

## Ошибки, которые поймали (этап 4)
- `#tree.tree-simple .node .name{font-size:19px}` перебивал `.node-compact .name` по специфичности — имя издалека было 9.9 px вместо 13. Правило вынесено с id и добавлено для compact.
- `partnersOf` передавал в `parents()` id вместо объекта — супруги не находились, пара не центрировалась.
- Свёрнутая ветка оставляла в ряду жён скрытых сыновей: `spouses` в демо-данных пуст, связь видна только через общих детей.
- Изотоническая раскладка сначала «уползала» вправо (клампинг только вправо) — заменено на PAVA.
- Пересортировка ряда по детям перемешивала братьев с чужой семьёй (68 пересечений на 92 линиях) — порядок фиксируется один раз по родителям (0 пересечений).
